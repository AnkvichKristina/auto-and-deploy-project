## Описание проекта

Проект имитирует работу торговой сети и автоматизирует полный цикл обработки данных о продажах:

Генерация CSV-файлов с данными продаж для нескольких магазинов и касс.
Автоматическое сохранение файлов в папку data.
Загрузка данных из CSV-файлов в базу данных PostgreSQL.
Автоматизация запуска процессов через Планировщик задач Windows.
Логирование всех этапов работы

## Структура проекта
project/  
data.py - Генерация CSV-файлов  
loading.py - Загрузка данных в PostgreSQL  
config_example.py - Пример конфигурационного файла  
requirements.txt - Список нужных библиотек    
data/ - Пример выгрузок  
sql/create_tables.sql - DDL для создания таблицы  
img/ - Скриншоты автоматизации и БД  
README.md  
.gitignore

## Установка проекта
### 1. Клонировать репозиторий
git clone <repository_url>
cd <repository_name>
### 2. Создать виртуальное окружение
python -m venv venv
### 3. Активировать виртуальное окружение
Windows:
venv\Scripts\activate
### 4. Установить библиотеки
pip install -r requirements.txt

## Настройка подключения к PostgreSQL

Создайте файл config.py по образцу config_example.py.

## Создание базы данных

Создайте базу данных PostgreSQL и выполните SQL-скрипт:

sql/create_tables.sql

Скрипт создаст таблицу sales, используемую для хранения данных о продажах

## Генерация данных

Для генерации тестовых данных выполните:

python data.py

После выполнения в папке data будут созданы CSV-файлы формата:

shop_num_cash_num.csv

## Загрузка данных в PostgreSQL

Для загрузки данных из папки data в базу данных выполните:

python etl.py

Во время загрузки:

- выполняется поиск файлов по шаблону число_число.csv;
- игнорируются посторонние файлы;
- данные объединяются в единый DataFrame;
- данные загружаются в PostgreSQL;
- после успешной загрузки обработанные CSV-файлы удаляются.

## Автоматизация

Для автоматизации используются задачи Windows Task Scheduler.
В проекте предусмотрены .bat файлы для автоматического запуска скриптов.

## Создание .bat файла

Чтобы создать его:

Откройте папку проекта
Создайте новый текстовый файл
Переименуйте файл, например:
start_data.bat — для генерации данных
start_loading.bat — для загрузки в БД
В файле нужно указать путь к исполняемому файлу вашего python.exe и путь к файлу скрипта.

### Генерация данных

Запуск ежедневно кроме воскресенья.

### ETL-процесс

Запуск ежедневно после выполнения генератора данных.

## Логирование

Для обоих скриптов реализовано логирование.

Логи сохраняются в папку:

logs/

Отдельные лог-файлы создаются для генерации данных и загрузки данных в базу.
